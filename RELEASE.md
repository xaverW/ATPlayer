# ATPlayer
<br />

**Release 1**

* Es gibt jetzt eine Blacklist, Audios können so ausgeblendet werden (in den Programmeinstellungen oder unter dem Filter)
* In den Einstellungen->Farben können die Icons auf Schwarz/Weiß umgestellt werden
* Für den Download-Namen gibt es einen neuen Parameter: %g für das Genre
* Programm-Oberfläche wurde geändert
* Die Anzeige der Downloads ist erweitert worden
* Es gibt einen neuen Filter: Thema oder Titel
* Filter können jetzt ein/ausgeschaltet (und damit ausgeblendet) werden
* Filter können gespeichert und dann auch wieder abgerufen werden (Filterprofile)
* Filter können in einem eigenen (externen) Fenster angezeigt werden
* Infofenster unter den Tabellen können in einem eigenen (externen) Fenster angezeigt werden
* ...

* Erste veröffentlichte Beta-Version
